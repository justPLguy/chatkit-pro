## 🇬🇧 English

### Install
**Recommended:** install from **Firefox Add-ons (addons.mozilla.org)** — it updates automatically. *(Link coming after Mozilla's review.)*

**For testing (temporary, removed when Firefox restarts):**
1. Download **`ChatKit-Pro-Firefox-v1.3.1.zip`** from **[Releases](../../releases)** and unzip it.
2. Open `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on…** and pick `manifest.json` from the unzipped folder.
4. Open [chatgpt.com](https://chatgpt.com) and click the round **🧰** button (or press Alt+Shift+K). The **CK icon** in the toolbar is the on/off switch: red = on, grey = off.

### What's inside
Same features as the Chrome version: bulk delete / archive / restore / rename chats, quick jump (Alt+Shift+J), tags on chats, bulk move to a ChatGPT project, shared links manager, Library image cleanup and download, folders and stars, export (Markdown, HTML, PDF, ZIP with one file per chat, Markdown + YAML for Obsidian / Notion, only the messages you pick), counter above the message box, timestamps, minimap with chat stats, bookmarks and notes, “Save” button on code blocks, chat width and font size, backup reminder, prompt library with tags and favorites, full-text search, cleanup rules, statistics, 6 panel themes, classic dark mode, 14 languages (EN, PL, FR, DE, ES, PT-BR, IT, NL, CS, UK, TR, JA, ZH-CN, KO).

### Permissions
| Permission | Why |
|---|---|
| `storage` | folders, stars, prompts, notes and settings — stored locally |
| `downloads` | saving Library files you choose |
| `chatgpt.com`, `chat.openai.com` | the panel works only on ChatGPT |

No servers, no analytics, no tracking. See **[PRIVACY.md](PRIVACY.md)**.

## 🇵🇱 Polski

### Instalacja
**Polecane:** zainstaluj z **Firefox Add-ons (addons.mozilla.org)** — aktualizuje się sama. *(Link pojawi się po recenzji Mozilli.)*

**Do testów (tymczasowo, znika po restarcie Firefoksa):**
1. Pobierz **`ChatKit-Pro-Firefox-v1.3.1.zip`** z **[Releases](../../releases)** i rozpakuj.
2. Otwórz `about:debugging#/runtime/this-firefox`.
3. Kliknij **Załaduj tymczasowy dodatek…** i wskaż `manifest.json` z rozpakowanego folderu.
4. Otwórz [chatgpt.com](https://chatgpt.com) i kliknij okrągły przycisk **🧰** (albo Alt+Shift+K). **Ikona CK** na pasku to włącznik: czerwona = włączona, szara = wyłączona.

### Co jest w środku
To samo co w wersji na Chrome: masowe usuwanie, archiwizacja, przywracanie i zmiana nazw czatów, szybki skok (Alt+Shift+J), tagi na czatach, masowe przenoszenie do projektu ChatGPT, menedżer udostępnionych linków, czyszczenie i pobieranie obrazów z Biblioteki, foldery i gwiazdki, eksport (Markdown, HTML, PDF, ZIP z plikiem na czat, Markdown + YAML dla Obsidiana / Notion, tylko wybrane wiadomości), licznik nad polem wiadomości, znaczniki czasu, minimapa z licznikami czatu, zakładki i notatki, przycisk „Zapisz” przy blokach kodu, szerokość czatu i rozmiar czcionki, przypomnienie o kopii zapasowej, biblioteka promptów z tagami i ulubionymi, wyszukiwanie pełnotekstowe, reguły porządków, statystyki, 6 motywów panelu, klasyczny ciemny motyw, 14 języków (PL, EN, FR, DE, ES, PT-BR, IT, NL, CS, UK, TR, JA, ZH-CN, KO).

### Uprawnienia
| Uprawnienie | Po co |
|---|---|
| `storage` | foldery, gwiazdki, prompty, notatki i ustawienia — zapisane lokalnie |
| `downloads` | zapisywanie wybranych plików z Biblioteki |
| `chatgpt.com`, `chat.openai.com` | panel działa tylko na ChatGPT |

Bez serwerów, analityki i śledzenia. Szczegóły: **[PRIVACY.md](PRIVACY.md)**.
