## 🇬🇧 English

### Install
**Recommended:** install from **Firefox Add-ons (addons.mozilla.org)** — it updates automatically. *(Link coming after Mozilla's review.)*

**For testing (temporary, removed when Firefox restarts):**
1. Download **`ChatKit-Pro-Firefox-v1.1.0.zip`** from **[Releases](../../releases)** and unzip it.
2. Open `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on…** and pick `manifest.json` from the unzipped folder.
4. Open [chatgpt.com](https://chatgpt.com) and click the **CK icon** in the toolbar (or press Alt+Shift+K).

### What's inside
Same features as the Chrome version: bulk delete / archive / restore chats, Library image cleanup and download, folders and stars, export (Markdown, HTML, PDF), timestamps, minimap, bookmarks and notes, prompt library, full-text search, cleanup rules, statistics, classic dark mode, 4 languages (EN, PL, FR, DE).

### Permissions
| Permission | Why |
|---|---|
| `storage` | folders, stars, prompts, notes and settings — stored locally |
| `downloads` | saving Library files you choose |
| `chatgpt.com`, `chat.openai.com` | the panel works only on ChatGPT |

No servers, no analytics, no tracking. See **[PRIVACY.md](PRIVACY.md)**.

## 🇵🇱 Polski

### Instalacja
**Polecane:** zainstaluj z **Firefox Add-ons (addons.mozilla.org)** — aktualizuje się sama. *(Link pojawi się po recenzji Mozilli.)*

**Do testów (tymczasowo, znika po restarcie Firefoksa):**
1. Pobierz **`ChatKit-Pro-Firefox-v1.1.0.zip`** z **[Releases](../../releases)** i rozpakuj.
2. Otwórz `about:debugging#/runtime/this-firefox`.
3. Kliknij **Załaduj tymczasowy dodatek…** i wskaż `manifest.json` z rozpakowanego folderu.
4. Otwórz [chatgpt.com](https://chatgpt.com) i kliknij **ikonę CK** na pasku (albo Alt+Shift+K).

### Co jest w środku
To samo co w wersji na Chrome: masowe usuwanie, archiwizacja i przywracanie czatów, czyszczenie i pobieranie obrazów z Biblioteki, foldery i gwiazdki, eksport (Markdown, HTML, PDF), znaczniki czasu, minimapa, zakładki i notatki, biblioteka promptów, wyszukiwanie pełnotekstowe, reguły porządków, statystyki, klasyczny ciemny motyw, 4 języki (EN, PL, FR, DE).

### Uprawnienia
| Uprawnienie | Po co |
|---|---|
| `storage` | foldery, gwiazdki, prompty, notatki i ustawienia — zapisane lokalnie |
| `downloads` | zapisywanie wybranych plików z Biblioteki |
| `chatgpt.com`, `chat.openai.com` | panel działa tylko na ChatGPT |

Bez serwerów, analityki i śledzenia. Szczegóły: **[PRIVACY.md](PRIVACY.md)**.
