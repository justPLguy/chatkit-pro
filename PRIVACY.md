# Privacy Policy — ChatKit Pro by JustPLGuy (Firefox)

*Last updated: 17 November 2026 · v1.1.0*

## English

**ChatKit Pro by JustPLGuy does not collect, sell or share any personal data.**

- **No servers.** The extension has no backend. It communicates only with `chatgpt.com` / `chat.openai.com`, using the session you are already logged in with, to perform actions you request (list, delete, archive, export chats; list, delete, download Library files).
- **Authentication.** Your ChatGPT session token is read from the ChatGPT page only to make these requests. It is kept in memory and never stored or sent anywhere else.
- **Local data.** Folders, stars, prompts, bookmarks, notes, cleanup rules and settings are stored in the browser's local extension storage. The optional full-text search index is stored in IndexedDB. All of it stays in your browser; you can export, import or remove it at any time (removing the extension deletes it).
- **Updates.** The version from Firefox Add-ons is updated by Firefox and makes no other requests. A temporary test install (loaded from the ZIP via about:debugging) checks the public GitHub API for a newer release when Firefox starts — without cookies, identifiers or any data about you or your chats.
- **No analytics, no tracking, no ads, no third-party code.**
- **Permissions:** `storage` (local data), `downloads` (saving Library files you choose), host access to `chatgpt.com` / `chat.openai.com` only.

## Polski

**ChatKit Pro by JustPLGuy nie zbiera, nie sprzedaje i nie udostępnia żadnych danych osobowych.**

- **Brak serwerów.** Wtyczka nie ma własnego zaplecza. Łączy się wyłącznie z `chatgpt.com` / `chat.openai.com`, używając Twojej zalogowanej sesji, aby wykonać akcje, które zlecasz.
- **Logowanie.** Token sesji jest odczytywany ze strony ChatGPT tylko do tych zapytań, trzymany w pamięci i nigdzie nie zapisywany ani nie wysyłany.
- **Dane lokalne.** Foldery, gwiazdki, prompty, zakładki, notatki, reguły i ustawienia są w lokalnej pamięci rozszerzenia, a opcjonalny indeks wyszukiwania w IndexedDB — wyłącznie w Twojej przeglądarce. Możesz je wyeksportować, zaimportować lub usunąć (odinstalowanie wtyczki je usuwa).
- **Aktualizacje.** Wersję z Firefox Add-ons aktualizuje Firefox — wtyczka nie wysyła żadnych innych zapytań. Tymczasowa instalacja testowa (z ZIP-a przez about:debugging) przy starcie Firefoksa sprawdza w publicznym API GitHuba, czy jest nowsza wersja — bez ciasteczek, identyfikatorów i danych o Tobie lub Twoich czatach.
- **Brak analityki, śledzenia, reklam i kodu firm trzecich.**
