# Privacy Policy — ChatKit Pro by JustPLGuy (Firefox)

*Last updated: 21 November 2026 · v1.5.0 · full policy (incl. the website): https://chatkit.justplguy.com/privacy/*

## English

**ChatKit Pro by JustPLGuy does not collect, sell or share any personal data.**

- **No servers.** The extension has no backend. It communicates only with `chatgpt.com` / `chat.openai.com`, using the session you are already logged in with, and only to do what you ask: list, delete, archive, restore, rename and export chats; move chats to your ChatGPT projects; list and delete your shared links; list, delete and download Library files (images and other files), show a read-only view of the Library trash, and check whether the chat a file came from still exists; show timestamps and the chat outline.
- **Authentication.** Your ChatGPT session token is read from the ChatGPT page only to make these requests. It is kept in memory and never stored or sent anywhere else.
- **Data in the extension's storage.** Folders, tags, stars, prompts, bookmarks, notes, cleanup rules and settings are stored in the browser's local extension storage. You can export or import them at any time (⚙ Settings); removing the extension deletes them.
- **Data in the ChatGPT site storage.** A few things live in the storage of the `chatgpt.com` page itself: the optional full-text search index (IndexedDB) and small UI states such as selected items, the panel view and a pause after ChatGPT's “too many requests”. They never leave your browser. Removing the extension does **not** delete them — clear the index in the “Full-text search” tab (“Clear index”) or clear the site data of `chatgpt.com` in your browser settings.
- **Updates.** The version from Firefox Add-ons is updated by Firefox and makes no other requests. A temporary test install (loaded from the ZIP via about:debugging) checks the public GitHub API (`api.github.com/repos/justPLguy/chatkit-pro/releases`) for a newer release — without cookies, identifiers or any data about you or your chats.
- **No analytics, no tracking, no ads, no third-party code.**
- **Permissions:** `storage` (local data), `downloads` (saving files you choose), host access to `chatgpt.com` and `chat.openai.com` only.

## Polski

**ChatKit Pro by JustPLGuy nie zbiera, nie sprzedaje i nie udostępnia żadnych danych osobowych.**

- **Brak serwerów.** Wtyczka nie ma własnego zaplecza. Łączy się wyłącznie z `chatgpt.com` / `chat.openai.com`, używając Twojej zalogowanej sesji, i tylko po to, żeby zrobić to, co zlecasz: lista, usuwanie, archiwizacja, przywracanie, zmiana nazw i eksport czatów; przenoszenie czatów do Twoich projektów ChatGPT; lista i usuwanie udostępnionych linków; lista, usuwanie i pobieranie plików z Biblioteki (obrazów i innych plików), podgląd kosza Biblioteki oraz sprawdzanie, czy czat, z którego pochodzi plik, nadal istnieje; znaczniki czasu i spis treści czatu.
- **Logowanie.** Token sesji jest odczytywany ze strony ChatGPT tylko do tych zapytań, trzymany w pamięci i nigdzie nie zapisywany ani nie wysyłany.
- **Dane w pamięci wtyczki.** Foldery, tagi, gwiazdki, prompty, zakładki, notatki, reguły i ustawienia są w lokalnej pamięci rozszerzenia. W każdej chwili możesz je wyeksportować lub zaimportować (⚙ Ustawienia); odinstalowanie wtyczki je usuwa.
- **Dane w pamięci strony ChatGPT.** Część rzeczy jest zapisana w pamięci samej strony `chatgpt.com`: opcjonalny indeks wyszukiwania (IndexedDB) i drobne stany panelu, np. zaznaczenia, widok i przerwa po komunikacie ChatGPT „za dużo zapytań”. Nigdy nie opuszczają Twojej przeglądarki. Odinstalowanie wtyczki ich **nie** usuwa — wyczyść indeks w zakładce „Szukaj w treści” („Wyczyść indeks”) albo usuń dane witryny `chatgpt.com` w ustawieniach przeglądarki.
- **Aktualizacje.** Wersję z Firefox Add-ons aktualizuje Firefox — wtyczka nie wysyła żadnych innych zapytań. Tymczasowa instalacja testowa (z ZIP-a przez about:debugging) sprawdza w publicznym API GitHuba, czy jest nowsza wersja — bez ciasteczek, identyfikatorów i danych o Tobie lub Twoich czatach.
- **Brak analityki, śledzenia, reklam i kodu firm trzecich.**
- **Uprawnienia:** `storage` (dane lokalne), `downloads` (zapisywanie wybranych plików), dostęp wyłącznie do `chatgpt.com` i `chat.openai.com`.
