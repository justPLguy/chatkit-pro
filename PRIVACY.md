# Privacy Policy — ChatKit Pro by JustPLGuy

*Last updated: 17 November 2026*

## English

**ChatKit Pro by JustPLGuy does not collect, sell or share any personal data.**

- **No servers.** The extension has no backend. It communicates only with `chatgpt.com` / `chat.openai.com`, using the session you are already logged in with, to perform actions you request (list, delete, archive, export chats; list, delete, download Library files).
- **Authentication.** Your ChatGPT session token is read from the ChatGPT page only to make these requests. It is kept in memory and never stored or sent anywhere else.
- **Local data.** Folders, stars, prompts, bookmarks, notes, cleanup rules and settings are stored in `chrome.storage.local`. The optional full-text search index is stored in IndexedDB. All of it stays in your browser; you can export, import or remove it at any time (removing the extension deletes it).
- **Update check.** Once a day the extension sends an anonymous request to the public GitHub API (`api.github.com/repos/justPLguy/chatkit-pro/releases`) to see whether a newer version exists. No cookies, identifiers or data about you or your chats are included.
- **No analytics, no tracking, no ads, no third-party code.**
- **Permissions:** `storage` (local data), `downloads` (saving Library files you choose), `scripting` (opening the panel in an already open ChatGPT tab), `alarms` (daily update check), host access to `chatgpt.com` only.

## Polski

**ChatKit Pro by JustPLGuy nie zbiera, nie sprzedaje i nie udostępnia żadnych danych osobowych.**

- **Brak serwerów.** Wtyczka nie ma własnego zaplecza. Łączy się wyłącznie z `chatgpt.com` / `chat.openai.com`, używając Twojej zalogowanej sesji, aby wykonać akcje, które zlecasz.
- **Logowanie.** Token sesji jest odczytywany ze strony ChatGPT tylko do tych zapytań, trzymany w pamięci i nigdzie nie zapisywany ani nie wysyłany.
- **Dane lokalne.** Foldery, gwiazdki, prompty, zakładki, notatki, reguły i ustawienia są w `chrome.storage.local`, a opcjonalny indeks wyszukiwania w IndexedDB — wyłącznie w Twojej przeglądarce. Możesz je wyeksportować, zaimportować lub usunąć (odinstalowanie wtyczki je usuwa).
- **Sprawdzanie aktualizacji.** Raz dziennie wtyczka wysyła anonimowe zapytanie do publicznego API GitHuba, czy jest nowsza wersja — bez ciasteczek, identyfikatorów i jakichkolwiek danych o Tobie lub Twoich czatach.
- **Brak analityki, śledzenia, reklam i kodu firm trzecich.**
