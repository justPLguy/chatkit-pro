    Why

    ChatGPT makes you clean up one chat at a time.

    Hundreds of test chats, thousands of generated images, no folders, no bulk actions. ChatKit Pro adds what's missing — right inside chatgpt.com.

    Without ChatKit Pro

    1. Hover a chat, click the three dots
    2. Click “Delete”, confirm
    3. Repeat for every single chat
    4. Deleted chats leave their images behind in the Library
    100 chats ≈ 300 clicks

    • Load all chats, filter (e.g. older than 30 days)

    • Delete, archive or move to a folder
    • Clean the Library the same way — with a size counter

    Features

    Everything you wished ChatGPT had.

    FAQ

    Questions

    Is it really free?

    Yes. Every feature, no limits, no subscription, no “Pro” upgrade. The “Pro” in the name is about what it can do, not about a price.

    Can it read or send my conversations somewhere?

    No. It works only on chatgpt.com and only sends the same requests the ChatGPT website sends when you click buttons yourself. There is no ChatKit Pro server — the only extra request (GitHub version only) is an anonymous daily check on GitHub for a new release. The code is open — you can check it.

    Can I undo a deletion?

    Deleted chats can't be restored — that's how ChatGPT works. Every bulk action asks for confirmation. If you're unsure, archive instead (archived chats can be restored) or export first.

    Which ChatGPT plans does it work with?

    It's built for chatgpt.com in the browser and doesn't depend on a plan. Some features (like the Library or Projects) appear only if your account has them.

    What happens when ChatGPT changes?

    ChatKit Pro uses ChatGPT's internal web API, which can change without notice. When something breaks, a fix is released on GitHub — report issues there.

    Is it in the Chrome Web Store?

    Yes! Install it from the Chrome Web Store — it updates automatically. The GitHub version is still available for manual installs.

    I installed it from GitHub. How do I switch to the store version?

    Your folders, stars, prompts and notes are stored per installation, so move them over: in the GitHub version open the panel → ⚙ Settings → “Export data (JSON)”. Remove the GitHub version, add ChatKit Pro from the Chrome Web Store, then ⚙ Settings → “Import data” and pick the file.

    Firefox?

    Yes! The Firefox version (140+) has the same features. It's in review on Firefox Add-ons; until then you can test it from the GitHub ZIP as a temporary add-on.

    How do I report a bug or contact you?

    Open an issue on GitHub or write to justplguy@gmail.com — bug reports, ideas and questions are all welcome.
